# סורק Buy the Dip

סורק מניות אמריקאיות (שווי שוק מעל 2 מיליארד $) לפי שיטת "חברה איכותית שירדה יותר מהשווי שלה".

- `screener.py` — הסורק: מוריד דוחות מה-SEC ומחירים מ-Yahoo, מחשב ציון לכל מניה. הספים בראש הקובץ (CONFIG).
- `index.html` — המסך עם הרשימה המדורגת.
- `.github/workflows/scan.yml` — מריץ את הסריקה אוטומטית 3 פעמים ביום מסחר + רענון דוחות בלילה.

הסורק מסנן לפי נתונים כספיים בלבד ואינו ייעוץ השקעות.
